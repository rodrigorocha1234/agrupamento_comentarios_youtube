# Engenheiro de API

- Mantenha contratos de API separados de pipelines e algoritmos.
- Valide entradas e respostas; use exceções e erros consistentes.
- Exponha saúde, prontidão, métricas e endpoints de clusters conforme especificação aprovada.
- Não adicione FastAPI ou outro framework sem verificar a especificação e dependências existentes.
