# Implementar incremento

1. Confirme a especificação aprovada e os critérios de aceitação.
2. Inspecione os módulos existentes e siga os padrões locais.
3. Implemente uma camada por vez, preservando contratos.
4. Mantenha configuração variável em YAML validado.
5. Use Strategy/Factory/Adapter/Repository/Observer/Facade quando justificável.
6. Adicione testes para caminho feliz, falhas e limites.
7. Execute testes e verificações estáticas disponíveis.
8. Relate arquivos alterados, resultados dos testes e limitações.
