# Observar o pipeline

- Inspecione primeiro os serviços e dashboards existentes.
- Defina métricas para coleta, bronze/silver/gold, atributos, treino, API e infraestrutura.
- Separe dashboards operacionais de dashboards de negócio.
- Instrumente erros, latência, throughput, retries, freshness e qualidade.
- Não duplique exporters, serviços ou dashboards sem necessidade.
